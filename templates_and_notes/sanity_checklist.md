Checklist for each participant, sanity checks. INTERAL MULTIPLEYE DOCUMENT; CANNOT BE GENERALIZED AND SHOULD NOT BE SHARED!

 - [ ] Obligatory break at least 300s (5 mins) for MultiplEYE, does not apply to MeRID
 - [ ] Blink ratio ok (exact value depends a bit but everything above 2% - 3% should be checked)
 - [ ] All validations performed before each trial (expect second practice trial, ok without)
 - [ ] Recalibration before trial done if respective screen has been shown
 - [ ] Comprehension above chance level (i.e. above 25%)
 - [ ] No technical issues (e.g. missing files)
 - [ ] Optional breaks when calibration got worse
 - [ ] Calibration when validation score were bad
 - [ ] Visible effort to keep validation scores good
 - [ ] Final validation
 - Plots
   - [ ] No skimming or skipping
   - [ ] No strange artefacts
   - [ ] Gaze overlays text in most cases (exceptions can be last pages, long trials, etc.)
   - [ ] Consistently looks at bottom right dot
   - [ ] Visible engagement with the text
   - [ ] No extreme values, e.g. super long or super short fixations. NOTE: rather long fixations, but can be individual
